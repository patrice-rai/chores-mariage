## 2. Combinaison gratuite, prête en une soirée

1. **Groupe WhatsApp** pour parler ; vidéos de référence envoyées **en « document »** pour éviter la compression.
2. **Framadate** pour fixer les répétitions (aucun compte, français, libre).
3. **Dossier kDrive ou album Google Photos** partagé par lien pour les vidéos de répétition. Pour lire au ralenti dans un navigateur, **YouTube non répertorié** reste le plus fluide.
4. **Lecteur de répétition** : **LoopStep** (boucle A-B, vitesses, miroir, décompte) ; ou Dance.io sur iPhone pour le comptage des temps.
5. **Choreographic** (gratuit, français) pour les placements si quelqu'un a un iPhone ; sinon un schéma photographié.
6. Une fiche 8 temps en tableur partagé.

Manques : pas de « qui maîtrise quoi », marqueurs de sections non partagés, cousins qui jonglent entre 4 outils.

## 3. Ce qu'un site sur mesure apporte, et fonctions minimales

Apports : **un seul lien**, sans compte, en français ; marqueurs de sections et de comptes partagés ; suivi « je maîtrise / pas encore » par cousin et section ; placements liés aux sections ; commentaires par vidéo.

MVP (pile PHP mutualisé ou Next.js) : accès par lien secret + mot de passe commun, prénom saisi une fois ; lecteur `<video>` H.264 avec `playbackRate` 0,25–1, `transform: scaleX(-1)`, boucle A-B, sections « 8 temps » en JSON (repartir de LoopStep, MIT) ; placements en grille SVG ; répétitions avec « je viens / je ne viens pas » ; grille cousins × sections ; commentaires horodatés ; PWA avec cache sur demande.

Vidéos : convertir sur le PC (`ffmpeg -i in.mov -c:v libx264 -crf 23 -preset medium -vf scale=-2:720 -c:a aac out.mp4`) — FFmpeg n'existe pas sur le mutualisé Hostinger. À 720p/CRF 23, une minute pèse 10–20 Mo.

Charge : 3 à 5 soirées avec Claude Code, 15–25 h humaines avec les tests sur de vrais téléphones.

## 4. Recommandation

Commencer par la combinaison gratuite dès ce soir ; construire le site si le groupe dépasse 6–8 cousins, s'il y a plusieurs chorés découpées en sections, ou si la famille veut voir qui maîtrise quoi. Un chorégraphe (≈ 390 € pour 6 h en IDF) n'est utile que pour l'ouverture de bal des mariés.

## 5. Pièges

- **HEVC** : les iPhone filment en HEVC ; régler Réglages › Appareil photo › Formats › « Le plus compatible », ou convertir en H.264.
- **Poids** : un 1080p brut d'iPhone dépasse 100 Mo/min.
- **PWA hors ligne** : Safari plafonne vers 1 Go ; sites non installés purgés après 7 jours.
- **Droits musicaux** : répétition et site privé entre cousins = cercle de famille (art. L122-5 1° CPI) ; publier la flash mob sur TikTok/Instagram en sort.
- **Droit à l'image** : garder les vidéos des cousins sur le lien privé.
- **Mot de passe commun** : prévoir de le changer, `noindex`.
