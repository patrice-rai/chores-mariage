4. **Accès** (spec § 6) : `scripts/nouveau-lien.php` (jeton 32 octets base64url, `jeton_hash`, `jeton_version` incrémentée, affiche le lien complet) ; routes `GET /e/{jeton}` (comparaison `hash_equals` sur le hachage, cookie `cm_acces` signé HMAC, redirection vers `/`), `GET /lien` (lien manquant ou périmé), `GET /` (entrée : neuf prénoms en boutons de 72 px dans un formulaire `POST /prenom` ; redirection vers `/moi` si le prénom est déjà choisi), `POST /prenom`, `POST /changer`, `GET /moi` (« Salut {prénom} » et la barre haute avec « Changer » ; le reste vient en phase 4) ; `app/acces.php` (vérification à chaque requête, 404 pour les routes admin sans `cm_admin`) ; `GET /admin/cle/{cle}` (pose `cm_admin` si la clé est bonne, sinon 404) et `GET /admin` (affiche la version du lien, le nombre d'entrées, les 50 dernières lignes du journal) ; `GET/POST /admin/lien` (« Nouveau lien », invalide l'ancien aussitôt, affiche le nouveau et un texte prêt à coller) ; CSRF par cookie + champ caché signé sur tout `POST` ; journal `entree`, `prenom`, `admin_lien`, `refus_jeton`, `refus_debit` sans IP.
5. **Sécurité** (spec § 10-11) : `app/securite.php` envoie sur chaque réponse la CSP sans `unsafe-inline` (`default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; media-src 'self'; font-src 'self'; connect-src 'self'; manifest-src 'self'; worker-src 'self'; frame-ancestors 'none'; form-action 'self'; base-uri 'self'; object-src 'none'`), `X-Content-Type-Options`, `Referrer-Policy: no-referrer`, `Permissions-Policy`, `Cross-Origin-Opener-Policy`, `X-Robots-Tag`, `Strict-Transport-Security` seulement si `ENV = production` ; `public/.htaccess` (réécriture, `-Indexes`, `noindex`, types MIME, cache des ressources, refus des `.sqlite`, `.git`, `chemin-app.php` en lecture directe) ; `public/robots.txt` `Disallow: /` ; limitation de débit (table `debit`, clés hachées SHA-256 avec sel du jour : entrée 10/min et 60/h par IP, prénom 20/h, réponse 429 en français) ; cookies `HttpOnly`, `SameSite=Lax`, `Secure` hors `ENV = dev`, `Path = BASE_PATH`.
